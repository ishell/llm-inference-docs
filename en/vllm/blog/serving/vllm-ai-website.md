## Why a new site

Almost all vLLM information lived on GitHub; event announcements and meetup slides landed as PRs on the code repo. That taxed people who wanted to merge code. Going forward: community events and logistics on the website; GitHub for development.

Trade-off: you can no longer PR a flyer into the main repo. Send website ideas to **website-feedback@vllm.ai**.

## New mailboxes

- **talentpool@vllm.ai** — internships and full-time résumés, forwarded to partner companies. Page says LLM inference hiring is hot.
- **collaboration@vllm.ai** — partners who want those résumés, meetups, or technical partnership. Gradual replacement for `vllm-questions@lists.berkeley.edu`.
- **social-promotion@vllm.ai** — Twitter/X, LinkedIn, RedNote, WeChat, etc.

## vLLM Daily

[vllm-daily](https://github.com/vllm-project/vllm-daily) summarizes the project every day. RSS: `https://github.com/vllm-project/vllm-daily/commits/main.atom`.

## Close

Research project → production inference engine, credited to the community. No TPS, no kernel.
